# Contributing

Thank you for your interest in contributing.

## Guidelines

* Keep the package structure flat.
* Add one file for each new input type (for example, `int.go`, `string.go`, `password.go`).
* If an option is only applicable to a single input type, keep it local to that file instead of adding it globally.
* Format all code with `gofmt` before committing.
* Ensure all tests pass before opening a pull request.

## Pull Requests

* Keep changes focused and self-contained.
* Include tests and example for new functionality when applicable.
* Use clear commit messages describing the change.
